写在前面

首先我们实验室目前所面临的情况是

绝大数人属于软件工程专业，极少数人是属于电子信息专业的学生，所以，我们并没有系统的学习过电路分析，数字电路，模拟电路，电力电子技术等等专业课，但是在画过一些pcb或者说是看过一些原理图的你们就会发现，原理图上的电路图和在初高中学过的不同，他似乎并没有构成回路，也有很多不熟悉的符号和元器件，这使得我们的理解变得非常困难，就会有一些人选择从头开始去看这些书籍或者相关的教学视频，希望通过自己的努力去弥补上自己专业的这份空缺，但是从我的经验来看，我会在这里就提出我在大二踩了无数坑后的想法：

不要让你对系统型学习的执念耽误你亲自动手做完整项目的时间

而且从我的角度看硬件学习的难处在于资料的过于分散，这其实也是硬件的知识体系所造成的。不管是原理图还是layout在不同的硬件领域都有不同的注意点，所以说在这里我给大家的建议是，学硬件，一定要多多交流，说实话，如果说是有个师傅带，那么可能你的半年努力可以抵过别人盲目的两年探索。所以说不要觉得自己学到的那点东西多么珍贵，将其开源分享互相借鉴学习，互相提出新的想法，和比自己的懂得多的人进行讨论，这种在硬件领域的思想碰撞在我看来是最好的进步方式

我曾经自学过电路原理，数电模电，电力电子，但是在这个过程中消耗了大多的时间，而且最后的效果不佳（有考研想法的同学可以大致的过一遍，但是在大一，大二这个阶段，既然选择了打比赛，这个时期大可可以将时间更有效率的利用起来）很多时候对于想要快速上手硬件的同学来说，这样的性价比太低，因为很多系统性的课程面向得对象是想要考研或者说是应对学校课程考试的学生，所以我给的建议是，直接去了结各种元器件的底层原理，因为很多电路的运行其实本身就是依据这些底层原理去运行的。

所以说，这个硬件的学习文档我也会先写各种元器件的底层原理，然后尽量的附上各个原理所对应的原理图（就是一般常用的电路，然后我会说说电路的运行情况），还有一些layout的注意事项，比如说是在进行layout时进行的回流路径和环路面积的规划等等，在基础元器件讲完后，会给大家详细讲解一下常用的dcdc芯片的运行原理用于给大家及逆行知识点上的回顾。

电阻

导体对于电流的阻碍作用

欧姆定律

  • U：导体两端的电压（V）
  • I：通过的电流（A）
  • R：导体的电阻（Ω）

\[I=\frac{U}{R} \text{等价于} U=IR\]

电阻的串并联

  • 串联： \(R=R_{1}+R_{2}+⋯\)，阻值相加，功率按阻值分配

并联：\(\frac{1}{R}=\frac{1}{R_{1}}+\frac{1}{R_{2}}+⋯\)，总阻值小于任一支路

串联分压，并联分流

在进行选型时需要注意的参数

阻值与精度

标称阻值：出厂标定的标准阻值，是电路设计的基础依据。

精度分级：±5% 用于普通限流

上下拉；±1% 用于分压

AD 采样；≤±0.5% 用于高精度测量与基准源。

此处的基准源是啥：用来提供一个几乎不随温度、电源、时间变化的标准电压。

单片机 ADC 采样、精密测量电路，要测量电压，就必须有一个已知的标准电压做对比。

功率

计算公式：P = I²R = U²/R，决定电阻的散热能力。

选型铁律：实际功耗 ≤ 额定功率 × 50%（强制降额设计，防止热损坏，提升可靠性）。

温度系数 (TCR)：在做采样电路时经常需要考虑该参数

衡量温度变化引起的阻值漂移。数值越小，阻值越稳定。精密仪表、基准电压源必须选用低 TCR 的金属膜或合金电阻。

噪声与材质特性

碳膜电阻噪声较大，不适合敏感信号；金属膜 / 薄膜电阻噪声极低，是低噪声放大电路的首选。

接下来是重点部分，电阻的各种作用：

限流：保护 LED、晶体管、芯片引脚，限制电流不超过安全值。

0欧电阻

0Ω电阻本质上不是“理想短路”，而是一个阻值标称为 0Ω、实际有几毫欧到几十毫欧的跳线元件。规格书通常不标“精度百分比”，而是标最大阻值，比如 ≤20mΩ、≤50mΩ。

0欧电阻作为电路设计中常用的元器件，作用很多，但是概括总结有4中

1.留位置;作为先留个 0Ω，后面要加磁珠、电感、电容、采样电阻时直接换调试

2. 跨接/跳线:走线过不去时跨一下，或者连接两个网络。相当于 PCB 上的“跳线帽”。

3. 单点接地:模拟地、数字地、功率地之间用 0Ω 连一下，实现形式上的单点连接。注意它不是隔离，高频下仍有阻抗。以及会分区/隔离，把不同电源域、不同地平面在某个点连起来，或者方便后期断开排查。

4. 测电流：把 0Ω 拆掉，串电流表；或者换成毫欧采样电阻测某一路电流。调试电源功耗时很常见

比如说该电路，此处的0欧电阻可以不焊接，如果发现纹波不符合自己的要求，那就可以将其更换为其他元器件，比如电容

电容

+

电容的本质是“储存电荷与电场能”，其全部特性基本都从这一点派生出来。

\[C=Q/U\]

储能：储能与电压平方成正比

公式：\(W=\frac{1}{2}CU^{2}=\frac{1}{2}QU=\frac{Q^{2}}{2C}\)

电容的串并联

并联;\(C=C_{1}+C_{2}+⋯\text{容量相加，}ESR \text{并联后降低。}\)

多个电容并联还可能因 ESL、布局形成反谐振，恶化某些频段的去耦效果。

串联：\(\frac{1}{C}=\frac{1}{C_{1}}+\frac{1}{C_{2}}+⋯\) 容量减小，耐压提高。此处的耐压为啥大了，核心原理就是电压被串联的电容分掉了

电压记忆：电容两端电压不能突变，电流可以突变；这是所有瞬态、滤波、延时行为的根源。 这是非常重要的特性，很多电路的就是根据该条原理实现的

容抗：\(X_{C}=\frac{1}{2πfC}\)

阻抗：\(Z_{C}=\frac{1}{jωC}\)

频率升高，阻抗下降

隔直通交：直流稳定后相当于开路，交流下频率越高越接近短路

上电瞬间电压为零，会产生很大的浪涌电流，

相位：纯电容中电流超前电压 90°。

  • ESR：等效串联电阻，决定发热、损耗和纹波能力。
  • ESL：等效串联电感，来自引脚和内部结构，高频下不可忽略。
  • 漏电阻：并非完全绝缘，存在漏电流，电解电容尤其明显

漏电流是啥：电容两端加直流电压后，除了短暂的充电电流，还会有持续的小电流流过，这就是漏电流

对于不同型号的电容来说，漏电流能力不同，比如说铝电解电容漏电最明显，薄膜电容或者陶瓷电容都很小，这部分自己下去再去查资料

关于esr,esl这两个东西在电路的设计中不可或缺，几乎在原理图设计和layout中必须考虑

寄生参数还会带来串联谐振、并联谐振和电磁干扰耦合。

这里先说说电容的种类，因为电容的种类很多，分装也不同，不同的电容都对应不同的功能，比较重要

1.贴片陶瓷电容：无极性，高频特性好，但是大容量难做到，高压容易啸叫，有电压容量衰减（DC 偏置）

2. 贴片 / 插件电解电容：容量大，低频滤波，电压范围宽，但是寿命有限、不耐高温、高频性能差，会鼓包漏液

3. 钽电解电容; 体积小、容量大、ESR 低、温度稳定性好, 价格高、反接 / 过压容易起火爆炸

4. 安规 X/Y 电容:这个电容我也不太熟悉，需要后续查资料

X 电容：跨火线 - 零线；

Y 电容：火线 - 地线

可以用作EMI 滤波，电源插座、适配器，但是绝对不能用普通电容替换

5.超级电容：RTC 后备电源、短时断电续航、储能。但是耐压低，漏电流大，不能替代电解做大电源储能

接下来就是电容常见功能所对应的电路

滤波：配合电阻或电感构成低通、高通、带通。

电源滤波本质就是用到了电容隔直通交的特性，交流信号对于电容的阻抗小，所以交流信号会进入电容，然后流进gnd，而使得相对纯净的直流电进入后级电路

低通滤波器（左边） 高通滤波器（右边）

信号从r1的左端进入，从右端流出。对于低通来说，高频信号从c1进入到gnd，所以低频通过就是低通

对于高通，高频信号通过c2，低频被阻拦，所以是高通滤波

在这里得说个概念，就是截止频率，截止频率就是高频和低频得分界线

截止频率得公式为\(f_{c}=\frac{1}{2πR_{1}C_{1}}\)。低于fc得是低频，高于得是高频

上图是一阶滤波，有个比较有意思得一个点就是超过截止频率之后，每超过10倍，信号就会衰减到原本得十分之一

但是上图是无源滤波器，具有很大的缺点，比如说对于信号得衰减太剧烈，输出阻抗高，后面接的负载会改变截止频率、滤波特性，带负载能力差，（为啥说是接了负载就会导致说截止频率改变，就拿左图来说，后级接了负载，负载得电阻和电容相当于并联，导致原本得rc时间常数发生变化，根据fc截止频率得公式发现，fc跟着改变，导致频率全部乱套。当然也有解决得办法要求后级负载的输入电阻 远大于滤波器输出阻抗（至少 10 倍以上），此时负载的影响才可以忽略。但是在工程一般做不到）

所以衍生出了有源滤波器就是会加运放

有源滤波器（运放构成）的输出阻抗极低，接近 0Ω。

运放输出级有很强的驱动能力，相当于一个理想电压源： 不管你接多大负载（在运放驱动能力范围内），负载和一个 0Ω 内阻的源并联，几乎不会改变电路内部 RC 的时间常数。运放起到缓冲隔离作用，把滤波网络和后级负载隔离开，负载不会影响前面滤波网络。（这部分采用了ai得话术，感觉这个比我自己说得更好懂一点，可以结合后续所说得运放进行食用）

去耦/旁路电容：为芯片提供本地电荷，抑制电源噪声。

其实去耦和旁路不同，去耦是为了不让mcu内部得噪声得流入其他mcu元件中，

而旁路则是将噪声旁路进了gnd

耦合：传递交流信号，隔断直流偏置。

谐振：与电感组成 LC 振荡或选频网络。

电感 L 和电容 C 组合在一起，在某一个特定频率下，电感的感抗和电容的容抗大小相等、相位相反，互相抵消，整个 LC 回路对外表现为纯电阻，这个现象就叫谐振；这个特定频率叫谐振频率。

谐振也分串联并联

对于串联得谐振而言，L 和 C 串在一起。谐振时总阻抗最小，电流最大；也叫电压谐振，L、C 元件上会产生远高于输入的高压。

对于并联得谐振而言; L 和 C 并在一起。谐振时总阻抗最大，回路内部环流很大；也叫电流谐振。

在电路得设计中谐振有好处有坏处

比如说

选频和滤波串联 LC 在谐振点阻抗最小（带通滤波），并联 LC 在谐振点阻抗最大。天线匹配网络靠这个特性，只让某些频率通过或衰减。

坏处有

不需要谐振的地方发生谐振，就是有害的！

电路寄生电感 + 寄生电容，意外谐振，产生振荡、尖峰，芯片误触发甚至烧毁；

陶瓷电容的压电效应啸叫，本质也和 LC 谐振 / 机械谐振相关；

陶瓷电容得压电效应是啥：MLCC 在电压波动时发生微小机械形变，带着 PCB 一起振动，PCB 像扬声器振膜一样发出声音。电容本身不是喇叭，也没有会响的部件，激励频率接近电容或 PCB 的机械谐振点，声音会特别明显。开关频率很高时，真正被听到的往往是 PFM（这个是脉冲得频率调制） 的突发重复频率、拍频或谐波。

布线不合理，电源、高速信号链路产生寄生谐振，造成 EMI 干扰。

谐振建议结合实际得视频进行理解，然后自己去搜集解决谐振得办法

定时：与电阻构成 RC 延时

电容通过电阻充电或放电时，电压变化是指数式的，不是瞬间跳变的。把这个缓慢变化的电压接到一个“有阈值”的器件上（门电路、施密特触发器、比较器、555 等），电压到达阈值时才翻转，于是就产生了延时。

这个就是最简单得延时电路，电源先流经电容进行充电，当电压达到二极管可以导通得时候，二极管才开始发光，达到延时得目的

电感

储存磁场能量的两端元件。核心规律来自法拉第电磁感应定律和楞次定律

通过线圈的磁通链变化时，会产生阻碍变化的感应电动势

电感对电流变化有“惯性”：电流想增大，它产生反向电压阻止；电流想减小，它产生同向电压维持。机械类比就是质量块。

公式为v(t) = L · di/dt

电感的核心特性是电流不能突变，

感抗：XL = ωL = 2πfL

阻抗：Z = jωL

所以说对于高频信号而言，阻值高，拥有有着隔交通直的特性

直流短路

高频开路

电压超前电流90

电感的常见分类有

功率电感：用于 DC-DC 电源储能，大电流、低 DCR，屏蔽型防 EMI。

磁珠 (Ferrite Bead)：高频下呈电阻特性，吸收噪声，电源入口必备。

共模电感：两组线圈同向绕制，抑制共模干扰，EMC 滤波核心元件。

差模电感：抑制差模噪声，常与 X 电容配合组成 LC 滤波。

色环电感：小功率小信号，色环标注电感量，类似电阻读法。

空心线圈：无磁芯饱和问题，射频功放、天线匹配常用。

在进行电感的选型时，一般需要考虑的参数：

1.电感量，他会决定储能能力和纹波的大小，而对于我们所常用的功率电感而言，一般的选型会采用0.47uh到100uh

在这里说个知识点，为啥电感会决定纹波能力呢

纹波的表达式\(ΔI=\frac{V\cdot Δt}{L}\)

当你的l大了，电流的变化率小，所以纹波小

从物理的角度理解的话：电感有电流惯性，电感量越大，阻碍电流变化的能力越强（楞次定律），电流不容易忽大忽小。

但是，不是l越大越好，也会产生问题;

动态响应变差：负载突然跳变时，电感电流变化太慢，电压会跌落 / 过冲。

饱和电流下降，大负载下磁芯饱和，电感直接失效；

饱和电流

这是选型时最关键的参数，当电感量下降百分之30时候的直流电源，超过这个饱和电流，磁芯饱和，电感量暴跌，电源的纹波就会剧增损坏芯片

此时巨大电流冲击 MOS 管，发热飙升，极易烧毁开关管

所以说在进行取值时，我们会选取大于电路峰值电流的1.5倍（这里的重点是测试上上电时的峰值电流）

温升电流

温升40摄氏度时的电流，由dcr铜损进行决定

这里有个新的名词dcr，dcr是指电感线圈是铜线，铜线有直流电阻 DCR（大电源必须选择低dcr）

此时的发热公式是：

\[P=I_{rms}^{2}\cdot DCR\]

这里说说温升电流和饱和电流的区别

温升电流就是电感可以长时间通过的电流

饱和电流就是经过电感的电流最大的界限，超过这个值就是电感量暴跌

Q值品质因数（这个我也不是很熟悉）建议自己在下面自行了解

\[Q=ωL/ESR\]

反映电感损耗。Q 值越高损耗越小。射频 / 谐振电路要求高 Q，电源滤波不敏感。

自谐振频率 SRF

电感与寄生电容谐振的频率。超过 SRF 后电感呈电容特性，失效。工作频率应远低于 SRF。

饱和电流和温升电流是最重要的两个参数，一顶要先考虑这两个东西

而共模电感是啥

通常是在一个磁芯上绕两个相同的绕组

共模电感是咋起作用的呢 如图所示，正常的电流运行路径是由正极出发回到负极，此时电流的方向相反，产生的磁场正好抵消，而且根据这个公式\[F=NI\]

由上述可知，同方向的磁动势相当于乘以2，磁芯接近饱和，呈现高阻，所以说将共模噪声给挡住

  • 由 PN 结（或金属-半导体结，如肖特基）构成，两端为阳极、阴极。
  • 最本质特性是单向导电性：正偏导通、反偏截止

Pn结就不说了

现在先说一个压降得概念

压降可以理解为这个元器件导通所消耗得电压，比如说二极管得导通电压时0.7v.输入电压时3.3v，二极管得左端得电压为3.3.右端得电压即为3.3减去0.7，是2.6v,所有说0.7就是二极管得压降

现在先说二极管得正向特性

1.存在死区电压，就是假如说一个二极管是0.2v才能导通，那么0.2就是他得死区电压，在低于这个电压时，二极管时不工作得

2. 导通后压降近似恒定

3. 电流随电压指数增长，电压略增即引起电流剧增，因此需串联限流电阻。

反向特性

反偏时只有很小的反向饱和电流 \(I_S\)：硅为 pA~nA 级，锗为 μA~mA 级。

反向电流随反压略有增大，但直到击穿前基本近似恒定。

击穿特性

  • 反向电压超过击穿电压 \(V_{BR}\) 后，反向电流急剧增大。
  • 齐纳击穿：通常 \(V_Z<5\text{ V}\)，隧道效应，具负温度系数。

雪崩击穿：通常 \(V_Z>6\text{ V}\)，载流子倍增，具正温度系数。

  • 在 5~6 V 附近温度系数接近零，这是稳压管常用工作区。
  • 只要外电路限流，击穿可逆，不损坏；否则热击穿永久损坏

电容特性

势垒电容：反偏时主导，随反压增大而减小

扩散电容：正偏时主导，与正向电流成正比，由存储电荷引起。

MOS 管

总体而言，mos管的种类是这两种

增强型 MOSFET：Vgs=0 时截止，需要加栅压才导通，也叫常闭型，绝大多数功率 MOSFET 都是这种。

耗尽型 MOSFET：Vgs=0 时已经导通，需要加负压或反向电压才能关断，也叫常开型，常见于恒流源、启动电路和部分射频电路。

Mos管是属于电压导通元器件

直流输入阻抗极高：静态栅极电流极小，但存在栅极漏电和栅极电容。

存在栅极 G、漏极 D、源极 S

接下来是他的工作区

截止区

Vgs < Vth，栅源电压小于开启阈值电压，

对 N 沟道增强型 MOSFET：Vgs < Vth 表示沟道还没形成，管子处于截止/关断状态，Id 几乎为 0，只有很小的漏电流。

对 P 沟道 MOSFET 要反过来理解，因为它的 Vth 通常是负值；比如 Vth = -2V，Vgs = -10V < -2V 反而是导通。

线性区（用作开关时）

V_DS < V_GS - V_th。

漏源电压小，沟道完整，电流大致跟 V_DS 成正比。此时它可以看成一只由 V_GS 控制的电阻。

饱和区

V_DS > V_GS - V_th

漏端附近的栅-沟电压差被消耗掉，沟道在漏端被“夹断”。继续加 V_DS，电流增加很慢，主要由 V_GS 决定。做放大器或恒流源时工作在这里。

对于n沟道和p沟道的电流流向

  • N 沟道：电子从源极 S 流向漏极 D，所以常规电流从漏极 D 流向源极 S。
  • P 沟道：空穴从源极 S 流向漏极 D，所以常规电流也从源极 S 流向漏极 D。

运算放大器

对于运放而言

有两个很重要的特性就是虚短和虚断

虚短是啥

就是指vp=vn（此处和运算放大器的负反馈有关

负反馈把输出的一部分送回反相输入端。若输出升高导致反相输入也升高，运放会减小输出；若输出降低，运放会增大输出。系统会朝着 `V+ ≈ V-` 的平衡点运动。

虚断

就是指0=ip=in，这是因为输入端电阻非常大，近似为断路

由此可知，虚短的产生就是利用了运放的负反馈

当然还存在正反馈

正反馈其实就是将反馈回到同相输入端，通常会变成正反馈

然后你就会发现输出会在两个饱和状态之间跳变，这就可以给大家延伸出施密特触发器

施密特触发器对于研究过单片机内部芯片gpio那部分的同学肯定有印象
