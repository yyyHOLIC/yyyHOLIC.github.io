简介

YOLO（You Only Look Once） 是计算机视觉领域最具里程碑意义的单阶段（One-Stage）实时目标检测算法家族。由 Joseph Redmon 等人于 2015 年首次提出，其核心颠覆性在于：将目标检测任务重构为单一的端到端回归问题，仅需对输入图像进行一次前向传播（Forward Pass），即可同时预测出图像中所有目标的边界坐标及其所属类别概率。

这个东西的功能说点能听懂的，就是先训出一个对照组，然后去到一个陌生的地方按图索骥，就像是教一个小朋友去买菜，给他一根菜叶一样。

创建虚拟环境（这里以VSCODE为演示编译器，pycharm一样的）

  1. 打开终端
# 创建一个名为 yolo_env，Python 版本为 3.10 的环境 （这里的名字和py版本根据需求修改）
如果要训练yolo的话python版本就推荐用3.10较稳定
conda create -n yolo_env python=3.10 -y

# 激活进入该环境（每次重新打开终端都需要执行这句） 
conda activate yolo_env
正确进入应该是在文件路径前有（yolo_env）

安装 GPU 版本的 PyTorch(如果没有GPU可以跳过）

  1. 打开 PyTorch 官网，根据你刚才安装的 CUDA 版本选择安装命令（由于这个版本是向下兼容的所以选择稳定版就行，就是比你的CUDA对应版本小的）。
  2. 检查pip的下载
    在你刚才打开的虚拟环境中
pip --version

 如果没有就执行

conda install pip -y
  1. （可换可不换）关于换源的问题，首先为什么要换源？当你在pip下载包的时候你会发现速度奇慢无比，有时还会下载失败，除去电脑真有问题的极大原因就是下载源的问题，因为很多包是外国网站的，为了解决这个问题，就要换源，但是在windous系统换源并不如linux方便，所以新手可以先不用换，等有能力再换。现在常用的国内镜像源是清华源和中科大源，由于今年清华源砍掉了conda的镜像所以我们换中科大源。

pip换源：

pip config set global.index-url https://mirrors.ustc.edu.cn/pypi/web/simple

验证方式：输入 pip config list，看到输出为中科大地址即说明成功。

conda换源：

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/conda-forge/
conda config --set show_channel_urls yes
  1. 验证：确认 PyTorch 能否调用 GPU

在当前虚拟环境中，输入以下命令测试：

python -c "import torch; print('PyTorch版本:', torch.__version__); print('CUDA是否可用:', torch.cuda.is_available()); print('当前显卡名称:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else '无')"

必须确保 CUDA是否可用 输出为 True。如果是 False，说明装成了 CPU 版 PyTorch 或驱动不匹配，需卸载重装。

初识YOLO

安装 YOLO 框架 (Ultralytics)

现在的YOLO已经成为了最主流的视觉识别方案，Ultralytics团队很活跃，更新很频繁，现在已经出到了YOLOv27，挺厉害的，但是我们做端到端部署和工业使用的并不追求先进而是稳定，现在应用最广的模型是yolov5，8，11

其中每个大版本又有细分，需要按照自己的要求选择，有v8s,n,m,l,x,其中n最常用是一个用于开发板的均衡版本，当需要识别的物品较小时可换成s（相应的算力要求高，相对的）。

目前 YOLOv8 和 YOLOv11 都集成在官方的 ultralytics 库中，安装极其方便，无需像早期版本那样手动克隆源码和安装冗长的 requirements.txt。

pip install ultralytics -i https://mirrors.ustc.edu.cn/pypi/web/simple

测试环境是否通畅： 运行一句官方自带的推理命令（会自动下载一个微型的预训练权重并检测一张示例图片）：

 yolo predict model=yolov8n.pt source='https://ultralytics.com/images/bus.jpg'

这就是yolo最经典的图像，相当于c的“HELLO WORLD”顺利做到这里算是yolo入门了

启动模型训练

你可以通过命令行或编写 Python 脚本来启动训练。推荐使用 Python 脚本，方便调参和调试。

新建一个 train.py 文件，写入以下代码：

from ultralytics import YOLO 

if __name__ == '__main__':
    # 1. 加载预训练模型（会自动下载）
    # 模型从小到大有：yolo8n.pt, yolo8s.pt, yolo8m.pt, yolo8l.pt, yolo8x.pt (也可换为 yolov11n.pt 等)
    # 新手建议先用 n (nano) 或 s (small) 测试速度和效果（前文已涉及）
    model = YOLO('yolov8n.pt')
以下的参数其实还有很多种比如还能设置旋转和亮度，目的是在有限的数据集中增加不同情况，提高最终模型的鲁棒性
    # 2. 开始训练
    results = model.train(
        data='my_data.yaml',   # 数据集配置文件的路径
        epochs=100,            # 训练总轮数（通常设置 100~300，不是越大越好，过大会出现过拟合）
        imgsz=640,             # 输入图像缩放尺寸（默认 640，小目标多可设为 1280）
        batch=16,              # 每次塞给显卡的图片数量（根据显存大小调整：8G显存建议设 8 或 16）
        device=0,              # 使用第 0 号 GPU（如果是 CPU 则写 'cpu'）
        workers=4,             # 数据加载线程数（Windows下如果报错内存不足，改为 0 或 2）
        project='runs/train',  # 训练结果保存的主目录
        name='exp1',           # 本次训练任务的名称
        patience=50            # 早停机制：如果 50 轮验证集指标没有提升，自动停止训练防过拟合
    )

在终端运行脚本开始训练：（通常时间较长，GPU占用会满，发热，建议加散热设备）

python train.py

常见报错处理：

  • CUDA out of memory（显存溢出）：将代码中的 batch=16 调小为 8 或 4。
  • Page file too small（Windows 虚拟内存不足）：将代码中的 workers=4 改为 workers=0 或 2。

评估训练结果、推理与导出

  1. 看懂训练结果（一般就只用看best.pt，这个就是最终的模型，至于下面的看过程曲线一般是熟悉后追求效果或者对比看的，没有找到图像？其实这些就是执行python train.py后在终端不断刷新的信息）

进入 runs/train/exp1/ 文件夹：

  • weights/best.pt：在验证集上表现最好的模型权重（后续部署和推理就用它）。
  • weights/last.pt：最后一轮的权重（用于意外中断后恢复训练 resume=True）。

  • results.png：训练过程曲线图。重点看两项：

  • box_loss / cls_loss：损失曲线应该呈现平滑下降并趋于收敛的趋势。

  • metrics/mAP50(B)：平均精度（取值 0\~1），越接近 1 代表模型越准（通常达到 0.85 以上在实际场景中就非常好用了）。
  1. 用训练好的模型测试新图片/视频
    新建一个 predict.py 脚本测试你的专属模型：代码写好后保存在 打开终端 打开虚拟环境 执行 python predict.py
from ultralytics import YOLO

# 加载你训练出的最优权重
model = YOLO('runs/train/exp1/weights/best.pt')//不要照抄根据自己的目录
# 对新图片、文件夹、视频甚至摄像头(source=0)进行推理保存结果
model.predict(
    source='test_images/',  # 可以是单张图路径、文件夹路径或视频路径 (.mp4)
    save=True,              # 保存画框后的结果图
    conf=0.5                # 置信度阈值（只显示大于 50% 把握的目标框）
)
